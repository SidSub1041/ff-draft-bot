The playbook

Get the copilot

Two ways to run it. The web app needs nothing installed; the extension docks it inside your draft room.

01

No download: open the web app

Go to sidsffcopilot.com/app, paste your Sleeper draft URL, done. Works in any browser, nothing stored on your machine.

Open the web app
02

Docked: install the extension

Read this before downloading. The extension asks for no account, reads no page content, and cannot make picks — it only shows the copilot beside your draft. Its full source is public at github.com/SidSub1041/ff-draft-bot, so you can read every line before loading it. Chrome will warn about Developer-mode extensions; that warning is about the install method, and the one-click Web Store version (which passes Google's review) is in preparation.
a.Download the zip below, then unzip it.
b.Open chrome://extensions, switch on Developer mode (top right).
c.Click Load unpacked and choose the unzipped folder.
d.Open your draft — the copilot docks on the right.
Download the extension SHA-256 395c02fca754b159942997d94e09bde5212c01827cb942af603865fd4b56062b

Verify the download in Terminal: shasum -a 256 draft-copilot-extension.zip

03

Yours: self-host the whole thing

The engine, panel and extension are open source — one command runs everything locally. Instructions at github.com/SidSub1041/ff-draft-bot. The hosted service is the same code.

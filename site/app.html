Sid's Draft Copilot

The hosted web app isn't live yet

The always-on hosted version of the copilot is still being stood up. Two ways to draft with it today:

1 · Install the extension

  1. Download the extension and unzip it.
  2. Open chrome://extensions, switch on Developer mode (top right).
  3. Click Load unpacked and choose the unzipped folder.
  4. Open a Sleeper draft — the copilot docks on the right. (It talks to a copilot server; see the self-host guide for running one.)

2 · Self-host the whole thing

The engine, panel and extension are open source — one command runs everything locally: GITHUB_LINK
